# คอร์สธุรกิจหรูหรา - เว็บไซต์ภาษาไทย

ยินดีต้อนรับสู่เว็บไซต์คอร์สธุรกิจหรูหราของเรา! นี่คือหน้า Landing Page ที่หรูหางดออกแบบมาเพื่อแสดงคอร์สเปลี่ยนชีวิตใน 30 วัน

## คุณสมบัติ

- ดีไซน์ธีมทองคำหรูหราพร้อมพื้นหลังดำเข้ม
- โครงสร้างที่ตอบสนองได้ทุกอุปกรณ์
- UI ที่ทันสมัยพร้อมเอฟเฟกต์ไล่เฉดสีและการเคลื่อนไหวอย่างนุ่มนวล
- ส่วนต่าง ๆ สำหรับส่วนนำ, ปัญหา, แผนการ, ประโยชน์, การกำหนดราคา, และคำถามที่พบบ่อย
- สร้างด้วย Tailwind CSS เพื่อการปรับแต่งได้ง่าย

## เทคโนโลยีที่ใช้

- HTML5
- Tailwind CSS
- JavaScript
- Google Fonts (Kanit)

## วิธีการปรับแต่ง

1. แก้ไขไฟล์ `index.html` เพื่อเปลี่ยนเนื้อหา รูปภาพ และราคา
2. ปรับแต่งการกำหนดค่า Tailwind ในแท็กสคริปต์หากจำเป็น
3. อัปเดตสีใน CSS โดยเปลี่ยนคำจำกัดความของสีทอง
4. แทนที่รูปภาพด้วยของคุณเองโดยอัปเดตแหล่งที่มาของรูปภาพ

## ไฟล์ที่รวมอยู่

- `index.html` - หน้าเว็บหลัก
- `contact.html` - หน้าติดต่อพร้อมแบบฟอร์ม
- `404.html` - หน้าแสดงข้อผิดพลาดแบบกำหนดเอง
- `README.md` - เอกสารนี้
- `assets/css/` - ไดเรกทอรีสำหรับไฟล์ CSS ที่กำหนดเอง
- `assets/js/` - ไดเรกทอรีสำหรับไฟล์ JavaScript ที่กำหนดเอง
- `assets/images/` - ไดเรกทอรีสำหรับรูปภาพ (เพิ่มเอง)

## การปรับใช้งาน

นี่คือเว็บไซต์แบบคงที่ที่สามารถปรับใช้งานบนบริการโฮสต์ใดก็ได้:
- Netlify
- Vercel
- GitHub Pages
- บริการโฮสต์เว็บแบบดั้งเดิมใด ๆ

เพียงอัปโหลดโฟลเดอร์ทั้งหมดไปยังแพลตฟอร์มที่คุณเลือก
